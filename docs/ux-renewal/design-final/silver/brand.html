유튜브 빨강 #FF0000 과 오류 빨강 #FA5570 은 밝기가 다르다(상대 휘도 0.21 대 0.28). 그래도 색만으로 구분하지 않고, 유튜브 빨강은 ↗ hover·로고 모양에만, 오류는 기호와 문장으로만 쓴다.

이 팔레트를 쓰는 규칙 RULES

해야 할 것과 하지 말 것

해야 할 것

  1. 강조는 밝기로 한다. 맥락은 실버, 핵심어·숫자만 흰색.
  2. 흰 면 버튼은 한 화면에 하나. 나머지는 테두리 버튼이나 글자 링크.
  3. 실버는 매 화면 보이게. 실버 판 로고, 실버 섹션 라벨, 실적 숫자의 실버 +, 실버 플레이 버튼 사진. 넓은 면은 실버로 칠하지 않는다.
  4. 흰색은 ‘지금·선택’ 한 가지 뜻. 현재 위치·정렬 열·선택 행·포커스.
  5. 기능 색은 앱 안에서, 글자와 함께. 초록 좋음·노랑 주의·빨강 나쁨, 항상 라벨·▲▼ 기호·칸 수를 붙인다(녹색약은 초록과 빨강을 밝기로만 구별).
  6. 회색은 무채색(R=G=B)만. 사진도 무채색으로 보정한 판(실버 플레이 버튼)을 쓴다.
  7. 작은 글자는 #7A7A7A 보다 밝게. 보조 글자 기본은 #949494.

하지 말 것

  1. 실버를 금속처럼 꾸미기. 그라데이션·광택·반사·글로우 없이 단색으로만.
  2. 유튜브 빨강을 다른 데 쓰기. 오류·할인·강조·쇼츠 배지에 #FF0000 금지. 오류는 #FA5570 + 기호 + 문장. ↗ 도 평소엔 회색.
  3. 기능 색으로 면 칠하기. 노란 경고 띠, 빨간 배너, 초록 버튼을 만들지 않는다(Great 작은 배지만 예외).
  4. 좋음을 흰색으로 표시하기. 흰색은 선택의 뜻이라 등급과 섞이면 헷갈린다.
  5. 청색기 회색과 보라·파랑 장식. slate·zinc·gray, 안내용 파랑도 쓰지 않는다.
  6. AI스러운 장식. 펄스 점·아이콘 상자·원형 숫자 배지·이모지·네온 번짐.
  7. 화면 문구의 긴 하이픈. 쉼표·가운뎃점·줄바꿈으로 나눈다.
